## Summary
Index of all reusable AIP templates and skill definitions (Preset Knowledge). Each task type has a Sample (PLAN) + EXEC template pair, grouped into Design & Testcase (AIP mandatory), Communication (Chat/Mail Confirm), Review, and Requirement. Templates target the Japan-project BrSE (VJP) profile but are mostly generic; there is no preset for Impact Investigation (a confirmed gap). AI use: locate the right preset AIP template/sample for a given task type.

Index/navigator document — it enumerates the canonical set; its mentions are the document itself, so it deliberately carries no relation edges (CR-AIWS-2026-07-048 DP-048-1).
