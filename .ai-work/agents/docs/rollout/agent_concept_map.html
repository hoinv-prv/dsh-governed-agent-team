AIWS Agent — bản đồ khái niệm, vai trò & kênh giao tiếp

HUMAN giao việc cho AI model ở main process. Model tự làm, hoặc spawn subagent (Claude agent) khi HUMAN chỉ định / AIP mô tả. Subagent có Task Desk riêng, mọi output trung gian ra Task Workspace, và feedback của HUMAN cũng qua model để ghi vào desk.

1. Sơ đồ tổng quan — đường đi của một việc

AI MODEL — main process Bên nhận việc từ HUMAN. Tự làm, hoặc spawn subagent.
CLAUDE AGENT (subagent) Được spawn để làm một task chuyên trách; có Task Desk riêng.
AIP Mô tả task theo STEP và chỉ định agent nào được spawn.
TASK DESK Bàn riêng của subagent: process · skill · memory · context.
TASK WORKSPACE Nơi ghi output trung gian — dùng chung cho cả hai đường.
HUMAN Giao việc & feedback cho AI model, quyết có spawn subagent hay không, gate mọi promotion.

2. Phân vai — ai giữ gì, ai quyết gì

Ba tác nhân thật sự "hành động" là HUMAN, AI model (main process) và subagent. AIP · Task Desk · Task Workspace là dữ liệu. Tooling là bên gác cổng, không suy luận.

3. Kênh giao tiếp — ai nói với ai, qua cái gì

AIWS là file-first: trừ cặp HUMAN↔model và lệnh spawn, mọi giao tiếp còn lại đều đi qua file trong repo — đọc lại được, lint được, không có kênh ngầm.

4. Sơ đồ runtime — một việc đi qua các thành phần

① Giao việc

HUMAN → AI MODEL

  • HUMAN nói với AI model ở main process — prompt hội thoại, hoặc lệnh /aiws-agent run start <agent> --aip AIP-EXEC-142 --step STEP-03.
  • Nếu việc đã được mô tả trong AIP: STEP khai Assigned Agent · Difficulty · Kind.
  • Không có auto-run — mỗi việc đều do HUMAN bấm.
›
② Quyết đường xử lý

AI MODEL — main process

  • Tự làm (main_session) khi việc không được chỉ định giao cho agent nào.
  • Spawn subagent (claude_subagent) khi HUMAN chỉ định, hoặc AIP mô tả — không tự ý spawn.
  • Trước khi spawn, tooling run_agent.py chạy gate: AIP status: active · Expected Outputs nằm trong Task Workspace · agent ∈ Assigned Agent · complexity_ceiling ≥ Difficulty.
  • Tooling dựng ARC (00_active_run_context.md) từ Task Desk của agent + nội dung task, rồi scaffold <TW>/runs/<run_id>/.
  • ✗ tooling không gọi model · ✗ không spawn · ✗ không tự làm task
›
③④ Thực thi

Main process hoặc subagent

  • Subagent đọc ARC + phần desk cần dùng (scoped-load: digest + hints, không đọc hết bàn).
  • Ghi output trung gian ra Task Workspace — cả hai đường đều vậy: output/, 04_findings, 05_open_questions, 07_output_draft, 08_capture_inbox.jsonl; tick progress.
  • Bí giữa chừng → messages_out.jsonl (kind: blocked) → run thành incomplete, chờ HUMAN.
  • business_rule / sot_conflict = HUMAN-only. Lệch rule đã khai → dừng và báo.
  • Xong → trả hand-off (summary + pointers); main process verify, không xử lại verdict.
›
⑤ Feedback & học

HUMAN → AI model → Task Desk

  • status: completed → run đóng; run_log.jsonl ghi lại sự kiện.
  • HUMAN nói feedback với AI model (hội thoại hoặc /aiws-agent-feedback); AI model ghi vào Task Desk: training/feedback_log.jsonl + candidate_queue.jsonl.
  • HUMAN tự sửa tay file trong desk là ngoại lệ hiếm — không phải đường chuẩn.
  • /aiws-agent-review-learning → HUMAN duyệt → hoặc vào memory/confirmed_memory.jsonl, hoặc apply thẳng vào process/ · skill.
  • Capture chung dự án → 08_capture_inbox.jsonl → Wiki candidate → HUMAN duyệt → Official Wiki.
  • Không auto-promotion ở bất kỳ lớp nào.

5. Việc đến từ đâu ⇒ run nằm ở đâu

Việc được mô tả trong AIP

Run nằm trong Task Workspace

Agent aip_driven + start có --aip → run không tạo workspace thứ hai. Nó materialize vào <TW>/runs/<run_id>/; desk chỉ giữ run_index.jsonl làm back-pointer.

Vì sao: bỏ hẳn vấn đề "hai workspace phải theo dõi". Nhiều subagent có thể cùng làm trên một Task Workspace (mỗi lúc một run active).

HUMAN chỉ định trực tiếp, không qua AIP

Run nằm trong desk

Không có --aip → run-folder nằm ở <desk>/workspace/active_runs/RUN-…, xong thì chuyển sang completed_runs/.

Lưu ý: đường này dành cho việc nhỏ. Việc đáng kể vẫn nên mô tả trong AIP để có kế hoạch và traceability.

6. Bất biến cần nhớ

HUMAN giao việc cho AI model ở main process, không giao thẳng cho subagent. Subagent chỉ xuất hiện khi được spawn.
Spawn subagent phải do HUMAN chỉ định hoặc AIP mô tả. Main process không tự ý quyết định lập một agent để làm hộ.
Task Desk là của riêng subagent. Đồ nghề và trí nhớ, không phải nơi nhận việc.
Output trung gian luôn ra Task Workspace — kể cả khi main process tự làm, không spawn ai cả.
Feedback cũng đi qua AI model. HUMAN nói với model, model ghi vào Task Desk dạng candidate; HUMAN duyệt rồi mới thành memory hoặc sửa đổi process/skill.
Tooling không gọi model, subagent không spawn agent. Chỉ main process được spawn, và chỉ khi được chỉ định.
