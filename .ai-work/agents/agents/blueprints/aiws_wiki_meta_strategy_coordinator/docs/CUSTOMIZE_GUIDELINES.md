# Customize Guidelines — Wiki Meta Strategy Coordinator

> Docs-parity set added by CR-AIWS-2026-07-017.

- **Variants = INSTANCES, not blueprints.** Per-project strategy style/context lives in the
  instance (`context/`, mission wording, memory) — do not fork the blueprint per project.
- **Customize:** mission focus (which wiki/meta areas), context refs (`wiki_references.yaml` —
  incl. `SRC-OVERVIEW-*` first-read pages), output emphasis in `wiki_meta_strategy.md`.
- **Do NOT customize away:** planning-only boundary (never runs other agents), no-auto-promotion,
  HUMAN gates (instance_creation / strategy_acceptance / memory_confirmation / blueprint_improvement).
- Shared pack-level rules (`_shared/common/lesson_capture_rule.md`) change once upstream — never fork.
- Anti-patterns: turning the coordinator into an orchestrator; writing strategy directly into
  Official Wiki; enabling every possible scope in one instance.
