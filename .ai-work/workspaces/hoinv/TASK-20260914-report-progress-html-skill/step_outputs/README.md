# Step Outputs

Each step of the AIP creates one output record (`STEP-NN.meta.yml`) when completed.

## Layout

- `STEP-NN.meta.yml` — step output metadata (one per step)
- `index.jsonl` — registry (auto-appended by `run step`)
- Actual deliverables live in workspace root or spec'd in `output_locator`

## Naming

- Meta file: `STEP-NN.meta.yml` (N = step index)
- Output ID: `OUT-<aip-nnn>-<N>-<seq>` (e.g., OUT-0089-03-01)
- Deliverable: `STEP-NN_<slug>.<ext>` (e.g., STEP-03_scan_results.md)

## Minimum Meta Fields

See `STEP-NN.meta.yml.template` — required fields are:
- `output_id`: `OUT-…`
- `step_id`: `STEP-NN`
- `result_type`: `output`
- `review_status`: `draft` / `approved` / `rejected`
- `output_locator`: relative path or `04_findings.md#STEP-NN`

Template generated by `run step`; author fills `review_status` + `output_locator` when step completes.

## Handoff Flow

When step N completes:
1. `run step` advances pointer to step N+1
2. Step N's output stub created (if not present)
3. Next step's ASC carries `## Previous Step Results` from this index
